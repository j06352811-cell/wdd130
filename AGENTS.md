# AGENTS

## Purpose
This repository is a static HTML/CSS learning workspace for BYU Pathway Worldwide WDD 130.
AI coding agents should treat it as a beginner-oriented student exercise collection, not a production app.

## Key guidance
- The workspace contains only static HTML, CSS, images, and simple page layouts.
- Do what the user asks in the project files, then let the user know when it is done. Do not give instructions in place of requested code changes.
- Inspect relevant pages, stylesheets, assets, assignment requirements, and nearby examples before editing.
- Treat written assignment requirements as authoritative and supplied wireframes as the visual reference. Do not invent sections or redesign beyond the request.
- Preserve the existing structure and content where possible, keeping changes focused on the task.
- Use plain HTML/CSS appropriate for WDD 130; avoid unnecessary frameworks and dependencies.
- Validate changes with available checks and a browser preview when practical. Report what was and was not verified.
- Use the project structure to understand scope:
  - `week01/` through `week05/` contain exercise files.
  - `wwr/` contains a sample site.
- There is no build system or backend; use plain HTML/CSS conventions.

## Notes for agents
- Keep explanations beginner-friendly, but perform the requested implementation rather than stopping at conceptual guidance.
- Ask for clarification only when an essential requirement or reference is unavailable and cannot reasonably be inferred.
- Summarize completed changes, validation, and any remaining manual checks after implementation.
